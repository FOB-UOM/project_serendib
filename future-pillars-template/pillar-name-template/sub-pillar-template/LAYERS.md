# Layer Guide

- `layer0-raw/records.v1.jsonl`: source excerpts and raw material.
- `layer1-instruction/records.v1.jsonl`: Sinhala instruction-response records.
- `layer2-reasoning/records.v1.jsonl`: reasoning-focused records.
- `layer3-structured/records.v1.jsonl`: schema-driven QA/structured entries.
- `layer4-advanced/records.v1.jsonl`: advanced future data types.
